# خادم صوت لمة شات على Cloudflare

الحالة: الكود مبني ومختبر محلياً؛ لم يُنشر على حساب Cloudflare ولم تُستخدم مفاتيح Agora الحقيقية أو يُختبر الصوت بين جهازين بعد. Firebase يبقى للحسابات والمجالس فقط. الخادم يقرأ المجلس بصفته المستخدم المسجل، ولا يحتاج مفتاح حساب خدمة Google أو ترقية Firebase إلى Blaze.

## المطلوب قبل التشغيل

1. حساب Cloudflare على Workers Free، مع مراجعة حدود الاستخدام. لا تحتاج نطاقاً خاصاً؛ يستخدم الخادم عنوان workers.dev. لا تفعّل خطة مدفوعة من أجل هذه التجربة.
2. قاعدة D1 باسم lamma-voice-sessions. أنشئها من لوحة Cloudflare، ثم افتح Console وشغّل محتوى schema.sql. الملف ينشئ جدول جلسات فقط ولا يحذف بيانات.
3. انسخ معرّف قاعدة D1 (ليس سراً) إلى d1_databases في wrangler.jsonc مكان COPY_REAL_D1_ID_HERE، وأزل التعليق عن هذا الإعداد. أو أضف D1 binding باسم DB من لوحة إعدادات Worker، ثم حدّث wrangler.jsonc بنفس المعرّف حتى لا تفقد الإعداد عند إعادة النشر عبر Git.
4. اربط مستودع GitHub والفرع codex/royal-council-voice مع Workers Builds. مجلد الجذر لهذا الخادم هو cloudflare، وأمر النشر npm run deploy. ثبّت الحزم باستخدام npm ci. لا ترفع مجلد node_modules.
5. من إعدادات Worker أضف AGORA_APP_CERTIFICATE بنوع Secret وليس متغيراً عادياً، واستخدم الشهادة المطابقة لـAGORA_APP_ID. لا ترسلها بالمحادثة ولا تضعها في GitHub أو HTML. معرّف التطبيق العام مضبوط على الموجود في النسخة السابقة؛ يجب تأكيد تطابقه مع مشروع Agora الحقيقي.
6. راجع ALLOWED_ORIGINS ليضم أصل موقع التطبيق الحقيقي فقط، بدون المسار؛ الافتراضي https://cjbp2mc8js-dotcom.github.io. أضف أصلاً آخر بفاصلة عند وجود استضافة مختلفة. لا تستخدم النجمة *.
7. بعد نشر الخادم، افتح /health: الاستجابة ok تعني أن الكود يعمل فقط، ولا تثبت اكتمال إعداد قاعدة البيانات أو الشهادة.
8. ضع عنوان HTTPS العام للخادم مع /voice-token في ملف voice-config.js بجذر التطبيق. لا تضع رمزاً مؤقتاً أو شهادة بهذا الملف.
9. انشر واجهة التطبيق بعد اكتمال الخادم واختبار تسجيل الدخول والمجلس. إذا كان هناك Service Worker يخزن HTML، حدّثه حتى يصل التعديل للموبايلات.

## بديل الإعداد من حاسوب

من مجلد cloudflare وبعد npm ci:

```sh
npx wrangler login
npx wrangler d1 create lamma-voice-sessions
# انسخ معرّف D1 الناتج إلى wrangler.jsonc، ثم:
npx wrangler d1 execute lamma-voice-sessions --remote --file=schema.sql
npx wrangler secret put AGORA_APP_CERTIFICATE
npm run deploy
```

المفتاح يُكتب في طلب Wrangler الآمن ولا يُضاف إلى ملف. يمكن استخدام Workers Builds ولوحة Cloudflare بدلاً من الحاسوب.

## ماذا يفعله الخادم؟

- يتحقق من توقيع Firebase ID token باستخدام مفاتيح Google العامة، ومن مشروعه ومصدره وتواريخ صلاحيته ومعرّف المستخدم؛ لا يقبل رمزاً لمشروع آخر أو هوية مرسلة من الواجهة.
- يجلب بيانات المجلس من Firestore باستخدام رمز المستخدم نفسه؛ قواعد القراءة الموجودة تبقى نافذة. لا تفتح قواعد Firestore للعامة بهدف تجاوز خطأ صلاحيات.
- يحدد وقت القفل من ساعة الخادم. يرفض القادم الجديد أثناء القفل ويقبل التجديد لجلسة قائمة غير منتهية. قراءة حالة المجلس وإنشاء الجلسة موزعان بين Firestore وD1، وليسا معاملة ذرية واحدة؛ قفل يحدث أثناء طلب دخول جارٍ قد يتزامن معه.
- يخصص قناة مشتقة من معرّف المجلس، ومعرّف Agora منفصلاً لكل جلسة.
- يحفظ الجلسة عشر دقائق ويجدد رمزها أثناء الاتصال؛ الخروج يحذف جلسة التجديد، ويغلق العميل المايك فوراً. الرمز الذي صدر بالفعل يبقى صالحاً عند Agora إلى نهاية مدته؛ لا تدّعِ سحب رموز صادرة فورياً بمجرد حذف سجل D1.
- يتحقق من JWT في كل طلب. سحب جلسات حساب Firebase المعطّل فورياً ليس مطبقاً هنا؛ رموز ID الموقعة يمكن أن تبقى صالحة حتى انتهائها، وفق تحقق Firebase القياسي خارج Admin SDK.
- ينظف ما يصل إلى 50 جلسة منتهية عند الدخول باستخدام فهرس وقت الانتهاء. لا تُخزَّن رسائل أو تسجيلات صوتية في D1، ولا يسجل الخادم رموز الحساب أو شهادة Agora.

هذا خادم رموز وتفويض فقط؛ Agora تنقل الصوت. الخطة المجانية لـCloudflare ليست وعداً بصوت Agora مجاني بلا حدود. راجع حدود Agora وتكلفتها في حسابك قبل إطلاق التطبيق للعامة. كذلك الخطة المجانية لـWorkers/D1 محدودة يومياً وبوقت CPU، وتتطلب مراقبة الاستخدام واختبار الأداء على النشر الفعلي. عند تجاوز الحدود قد تتوقف الطلبات.

## الفحص

من جذر المستودع: node --test tests/voice.test.js

من cloudflare:

```sh
npm ci
npm test
npm run build
npm run test:runtime
```

نجح 12 اختباراً للمايك والسياسة و8 اختبارات للخادم والتحقق بتوقيع RSA وقاعدة SQLite حقيقية. ونجح فحص بيئة Workers المحلية مع D1 وتوليد رمز Agora وتجديد الجلسة والقفل والخروج، باستخدام Firebase وهمي وشهادة تجريبية. لا يعادل ذلك اختبار شبكة صوتية بين جهازين.

بعد النشر: جرّب حسابين وجهازين مع سماعات في نفس المجلس، ثم مجلسين منفصلين، والكتم والنزول والخروج ورفض إذن المايك وانقطاع الإنترنت، وتجديداً لأكثر من عشر دقائق. اقفل المجلس بعد دخول الحساب الثاني، وتحقق من بقاء صوته ومنع حساب ثالث جديد. لم يُعد تدقيق نظام الماسات أو قواعد كتابته بهذه المهمة.
