# Royal crowns v2

`crowns-v2.webp` is the alpha-preserving WebP delivery version of a newly generated 2×2 crown atlas. Quadrants map to Royal 1 (rose gold/turquoise), Royal 2 (platinum/sapphire), Royal 3 (gold/amethyst), Royal 4 (gold/emerald). Render with CSS at 200% × 200%. Generated with the built-in image generation tool; WebP conversion retains transparency.

Prompt: One perfectly aligned 2×2 production sprite atlas of four luxury realistic 3D jeweled crowns on transparent background, no text or watermark. Identical scale, front three-quarter view, each crown inside its equal quadrant: rose-gold/turquoise/pearls; platinum/blue sapphire/diamonds; imperial yellow gold/amethyst/purple velvet; extravagant emerald and gold sultan crown with arabesque arches and diamond pavé. Premium collectible rendering, physically plausible reflective metal, faceted jewels, studio product lighting, clear small-size silhouettes.
