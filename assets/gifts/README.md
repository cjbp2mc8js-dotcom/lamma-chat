# Royal council gift artwork

`royal-gifts-atlas.webp` is a 4-column, 3-row transparent gift sprite atlas generated using the built-in image generation tool and compressed to WebP for the app. Row-major ordering matches `giftItems` in `mount-voice.js`.

Create exactly twelve premium highly realistic 3D gift objects, each centered in its own equal-sized square tile with generous 15% empty padding on every side. Transparent background throughout. Rich real material textures, photorealistic polished metal and gems, lifelike glass and velvet, beautiful studio highlights, fine details and subtle localized magical sparkles like high-end social voice-room virtual gifts. Every tile is independent and uniformly sized; each complete object fully contained within its tile. No contact sheets of UI, no flat vector icons, no emoji, no watermark. Keep backgrounds alpha transparent, with any halo strictly within tile.
